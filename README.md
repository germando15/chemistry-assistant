# Documentation

## Recherche d'un élément

L'utilisateur peut rechercher un élément en utilisant :

* Son nom
* Son symbole
* Son numéro atomique

## Calcul de la masse molaire

Entrer une formule chimique :

Exemple :

H2O

Résultat :

18.015 g/mol

## Calcul du nombre de moles

Formule :

n = m / M

où :

n = nombre de moles

m = masse (g)

M = masse molaire (g/mol)
